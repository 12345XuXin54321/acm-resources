# D. Grid Counting

## 题意

有一个 $n \times n$ 的网格，开始时每个格子颜色都为白色。
Alice 想要把满足一些条件的格子涂成黑色。

令 $(x_1, y_1), (x_2, y_2), \ldots, (x_m, y_m)$ 为涂成黑色的格子。
给定一个长度为 $n$ 的数组，以下条件必须满足：
* 第 $k$ 行，有 $a_k$ 个下标 $i$ 满足 $x_i = k$ ，
也就是第 $k$ 行有 $a_k$ 个黑色格子。
* 每一个 $k$ ，有且只有一个下标 $i$ 满足 $\max(x_i, y_i) = k$
* 每一个 $k$ ，有且只有一个下标 $i$ 满足 $\max(x_i, n + 1 - y_i) = k$

计算有多少个可能的涂色后的网格。答案对 $998244353$ 取模

## 思路

每行的 $y$ 的范围是 $\min(x, n - x + 1)$ 。
每一列必须有一个格子被涂色。

可以从给出的 $x$ 的数量逆序来看， $x = i$ 时已经填了
$x > i$ 的部分，所以能填的位置为剩下的部分。
可以用组合数来求涂色的方案数。
