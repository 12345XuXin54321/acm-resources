# C. Rabbits

## 题意

有 $n$ 个花盆排成一排，有一些有花，其它是空的。
给出一个 `01` 字符串， `0` 代表空， `1` 代表有花。
你有一些兔子，想放到每个空花盆中。每个兔子可以向左或向右看。

但是兔子很顽皮，想要跳。每个兔子准备跳到它们看的方向的下一个花盆。
但是当这个地方有兔子，或者有其它兔子准备跳到相同位置时，就不会跳过去了。
兔子不会跳出边界。

你需要选择兔子的方向，让它们永远不会跳走。
需要判断是否有一个符合要求的排列方式。

## 思路

开头或结尾为0时，添加 `00` ，
然后以长度大于1的连续的全1字符串切割。

此时分割后的字符串可以看作首尾是无数个1，
即首尾的第一个0需要向内侧。

从开头遍历字符串，如果连续的0的长度超过1，
则可以有1个可选择是否匹配的0，之前的0可以算匹配成功。

如果没有，则需要看0的数量，需要是偶数才能互相匹配。
